### The proven split recipe (fourth clean run this session)
1. Baseline: `cargo test -p <crate>` (with the right `--features` if tests are gated) green BEFORE touching anything; record the pass count.
2. Read the whole file; map natural responsibility boundaries.
3. Convert `foo.rs` → `foo/mod.rs` + siblings. `mod.rs` keeps anything callers outside the new dir reach via unchanged paths (or re-exports it).
4. **Visibility across the new module boundary — four cases seen so far:**
   - Private helpers/consts a *test child of the parent* reaches (`FALLBACK_LINE`, #318; `english_pack`, this session): keep them IN `mod.rs`.
   - A `pub(super)` method that *parent-level tests* call directly (`build_turn_prompt`, #320): re-declare as `pub(in crate::<parent-path>)` — same effective reach, test files stay untouched.
   - A private helper/type a *test child* reaches by bare name via `use super::*` but which now lives in a *sibling* submodule (`is_factual_question*`, `Passage`, this session): mark the item `pub(super)` in the submodule and add a `#[cfg(test)] use <submod>::<name>;` (PLAIN, not `pub(crate) use` — E0364) in `mod.rs`. Types come free the same way (`#[cfg(test)] use primer_core::knowledge::Passage;`).
   - A helper whose only caller moves with it (`stream_inference_response`, #320): narrow to private.
5. Fix moved relative paths: prefer absolute `crate::…` imports (or `super::` for a re-exported sibling) in the new submodules. (`mod.rs` itself keeps plain `super::…` — its depth is unchanged.)
6. Verify: pub-surface diff empty (`grep -oE 'pub (struct|enum|fn|const|async fn|trait|type) [A-Za-z_]+' | sort -u`, old vs new — **include `type`**), crate suite count matches baseline, feature-combos clippy if cfg arms exist, full-workspace `cargo test`, clippy `-D warnings`, fmt `--check` (run fmt AFTER the split).

## Patterns to reuse, not reinvent

- **The 6-step split recipe above** — new wrinkle this session: a test child reaching a private helper/type that moved to a *sibling* submodule is fixed with `pub(super)` on the item + a **plain** `#[cfg(test)] use <submod>::<name>;` in `mod.rs` (NOT `pub(crate) use` — that's E0364 against a `pub(super)` item). Types the test file used via the old flat-file glob (`Passage`) get the same one-line `#[cfg(test)] use` treatment.
- **Pub-surface diff must include `pub type`**. Full regex: `pub (struct|enum|fn|const|async fn|trait|type) [A-Za-z_]+`. Note it deliberately does NOT match `pub(super)`/`pub(crate)` — those are internal, so re-declaring a private item as `pub(super)` does not perturb the diff.
- **Doc-drift hunt recipe:** after a split, grep the moved file's name AND its key symbols across README/ROADMAP/CLAUDE. This session: the only doc reference to update was the CLAUDE.md `prompt_builder` module bullet; the `prompt_builder::tests` / `decide_intent()` mentions stayed accurate.
- **Use ABSOLUTE paths for shell tools** — Bash cwd resets between calls. `git show <ref>:<path>` wants the repo-root-relative path (`src/crates/…`); this session diffed against `HEAD:` (the flat file still existed there) rather than `main:`.
- **A grep final pipe stage returns exit 1 on zero matches** — the workspace-test command's exit 1 was just the trailing `grep 'FAILED'` matching nothing (= success). Check the `test result:` / `Finished` lines, not the pipeline exit code.
- **Branch each PR off `main`, not off the previous branch.**
- **Run long cargo passes with `run_in_background: true`**; the harness notifies on completion — no polling needed. Do NOT chain `sleep`; the harness blocks it.
