# English stopwords for KB BM25 retrieval (issue #386).
#
# One lowercase alphanumeric token per line; `#` starts a comment line.
# Entries must be in the form `primer_core::fts_util` hands the filter:
# punctuation already stripped, so "don't" is listed as "dont".
#
# Function words + contraction forms + conversational fillers. Words that
# can carry topic meaning in a child's question ("near", "light", "move",
# "work", "up", "down", "hot") are deliberately NOT here, nor is "not":
# #309 keeps negation a searchable term. "how" stays a term too: it asks
# for a mechanism and explanatory passages are worded that way, so
# dropping it cost recall ("how does my dog see in the dark" lost
# `seed:en:eyes-sight` from the top 5).
